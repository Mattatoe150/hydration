How to add or correct spots

This map is community-maintained. The easiest ways to help:

  • ➕ Add / fix → pick a type → click the exact spot on the map → submit. Best for a drinks machine, a shop, a petrol station with a shop, or a water tap you know.
  • Fix an existing spot: click its pin, then ⚑ Report — e.g. “no shop here”, “doesn't exist anymore”, or “wrong info”.
  • Every submission is checked by the maintainer before it's trusted, so nothing you or anyone else adds can break the map.
  • To improve the underlying data for every map, add it straight to OpenStreetMap — the StreetComplete app makes this a 2-tap job while you're out.
